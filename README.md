# 📊 Stock Price and Volume Analysis Dashboard

## 📌 Project Title

**Stock Price and Volume Analysis Dashboard**

## 📁 File Name

`POWER BI TASK_3(3).pbix`

## 📝 Project Description

This Power BI project focuses on analyzing **stock price and trading volume data** using interactive visualizations.

The dashboard provides insights into:

* Stock price statistics
* Trading volume trends
* Closing price movements
* 20-day moving average
* 50-day moving average
* Date-based filtering
* Price and volume comparison

The report was created using **Microsoft Power BI** to transform stock market data into an interactive and easy-to-understand dashboard.

---

## 🛠️ Tools Used

* **Microsoft Power BI Desktop**
* **Power Query**
* **DAX**
* **Data Modeling**
* **Data Visualization**

---

## ⚙️ Operations Performed in Power BI

### 1. Data Loading

* Imported stock-related data into Power BI.
* Used stock data for price and volume analysis.
* Used the `Dim_Date` table for date-based analysis.

### 2. Data Preparation

* Prepared and organized the stock data for analysis.
* Organized date and stock-related fields.
* Used the date field for time-based visualizations.

### 3. Data Modeling

* Used the `Dim_Date` table for date-related analysis.
* Used the `Shopify Stock` table for stock volume information.
* Created and used DAX measures for stock calculations.

### 4. DAX Measures

The dashboard contains the following measures:

* **Latest Close** – Identifies the latest closing price.
* **Lowest Price** – Identifies the lowest stock price.
* **Highest Price** – Identifies the highest stock price.
* **Average Volume** – Calculates the average trading volume.
* **Close Price** – Used for stock price trend analysis.
* **20 Day Moving Average** – Calculates the moving average over 20 days.
* **50 Day Moving Average** – Calculates the moving average over 50 days.

---

## 📊 KPI Cards

Four KPI card visuals were created to display important summary values:

* Latest Close
* Lowest Price
* Highest Price
* Average Volume

These cards provide a quick overview of the stock data.

---

## 📅 Date Slicer

A **Date Slicer** was added to the dashboard.

It allows users to select a particular date or date range and dynamically filter the dashboard visuals.

---

## 📈 Stock Price Trend Analysis

A line chart was created using:

* Date
* Close Price
* 20 Day Moving Average

This visualization helps compare the actual closing price with its 20-day moving average.

---

## 📉 50 Day Moving Average Analysis

Another line chart was created using:

* Date
* Close Price
* 50 Day Moving Average

This visualization allows users to compare the closing price trend with the 50-day moving average.

---

## 📦 Trading Volume Analysis

A combination chart was created using:

* Date
* Sum of Volume

This visualization represents how trading volume changes over time.

---

## 📊 Price and Volume Comparison

A combination chart was created to compare:

* Trading Volume
* Close Price
* Date

This provides a combined view of stock price movement and trading activity.
